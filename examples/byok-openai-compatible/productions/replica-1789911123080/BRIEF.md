## 1. 这条片子为什么成立（保留的不是文案，是关系）

参考片的威力不在画面精致，而在于四个**语义—时机绑定关系**。这些必须原样保留：

| # | 要保留的关系 | 参考片证据 | 换成你的产品后 |
|---|---|---|---|
| R1 | **「延迟满足」开场**：用具体的使用时长/次数，把「推荐」变成有代价的结论 | 0:00.1「穿了一個月洗了好幾遍才敢分享的短袖」 | 换成你产品的**可量化使用事实**（用了几周 / 用了多少次 / 空了几瓶 / 洗了几次） |
| R2 | **卖点即切点**：每个卖点开口的瞬间切一次画面，画面替口播打重音 | 0:02.6 / 0:04.3 / 0:07.0 / 0:09.9 / 0:13.8 / 0:15.1 / 0:17.4 | 切点位置不动，只换「被切的那个词」 |
| R3 | **先硬后软**：0:03–0:09 全放镜头能证实/证伪的硬指标，0:10 之后才放主观体感 | 硬：立起来、不会皱、领口平整、二本针；软：宽松有余量、免打理、遮肉 | 硬：【待填 — 你产品可被镜头验证的指标】；软：【待填 — 体感/省心类】 |

## 2. 受众（新主体沿用同一行为模型）

参考片受众是 25–40 男性、信息流刷到、价格敏感、决策快、**对「博主刚拿到样衣就吹」极度过敏**。

换产品后，受众画像换成你产品的同类人群，但以下行为特征必须保留，剧本按它写：

- 3 秒内不给出「我替你试过了」的姿态 → 划走
- 听到「大家好 / 今天给大家推荐」→ 划走
- 听到硬指标（可验证）→ 留下；听到纯形容词 → 划走
- 听到官方促销句式 → 广告感触发，划走
- 全片只给一次 CTA，且必须短促

## 3. 段落结构表（照抄时间轴）

全片**一段连续口播，零停顿、零口癖、零过渡语**，靠切镜换段。总口播 108–118 字，语速 ≈ 5.5 字/秒。

| 段 | 时间码 | 时长 | 字数 | 段落职能 | 画面变化 |
|---|---|---|---|---|---|
| **P0 钩子** | 0:00.0 – 0:02.6 | 2.6s | 14–18 | 自用验证，不给产品名、不给价 | **禁止**切镜（见 §5 例外） |
| **P1 硬指标 A** | 0:02.6 – 0:04.3 | 1.7s | 9–11 | 兑现悬念，最强可验证卖点 | 切 @0:02.6 |
| **P2 硬指标 B** | 0:04.3 – 0:07.0 | 2.7s | 13–16 | 第二个硬指标 + 状态描述 | 切 @0:04.3 |
| **P3 工艺/细节** | 0:07.0 – 0:09.9 | 2.9s | 14–17 | 结构、做工、看不见的地方 | 切 @0:07.0 |
| **P4 体感/省心** | 0:09.9 – 0:13.0 | 3.1s | 15–18 | 转主观：好用、省事、适配 | 切 @0:09.9、@0:10.0、@0:10.2 |
| **P5 价格 + 反向补位** | 0:13.0 – 0:16.2 | 3.2s | 16–19 | 口语价锚 → 立刻反打 | 切 @0:13.8、@0:15.1 |
| **P6 收束 CTA** | 0:16.2 – 0:20.2 | 4.0s | 20–24 | 别犹豫 + 使用场景 + 短促行动词 | 切 @0:17.4 |

**P6 内部三段式（不可合并、不可调序）**：
1. 打消犹豫：「【受众统称】别犹豫」
2. 追加一个使用场景，把购买理由翻倍：「还能当作【第二场景】」
3. 短促行动词，2 字或 4 字：「冲冲冲」

## 4. 逐句口播稿（句式保留，名词替换）

> 规则：**句式骨架照写，方括号内换成你的主体**。每句都必须落在上面表里的字数区间，超了就删形容词，不要拉长时长。

```
[P0 0:00.0]
用了【时长/次数】、【量化验证动作】才敢分享的【产品品类】，

[P1 0:02.6]
【可验证硬指标 1，一句话说完】，

[P2 0:04.3]
【可验证硬指标 2】、【状态/表现描述】，

[P3 0:07.0]
【结构 / 做工 / 用料细节】，

[P4 0:09.9]
【使用体感】、【省心点】，

[P5 0:13.0]
【口语化价格锚点】的价格性价比直接拉满，

[P5 续 0:15.1]
但【品质类褒义词，如：好看 / 好用 / 耐看 / 有型】，

[P6 0:16.2]
【受众统称】别犹豫，还可以当作【第二使用场景】，
【2–4 字行动词】。
```

**替换对照示例（仅示意句式，不要照抄内容）**

| 参考片原句 | 你要写成 |
|---|---|
| 穿了一個月洗了好幾遍才敢分享的短袖 | 用了【X 周 / 空瓶 X 个】才敢安利的【你的品类】 |
| 高科重面料可以立起来 | 【你的第 1 个硬指标，镜头一拍就能证明】 |
| 面料流出不会皱 眼膜就平整 | 【第 2 个硬指标】+【状态结果】 |
| 空间包边设计 二本针走线 | 【结构/工艺/成分/参数细节】 |
| 30多米的价格性价比直接拉满 | 【口语价锚】的价格性价比直接拉满 |
| 但穿好看又有型 | 但【品质褒义词】 |
| 兄弟们别犹豫 还可以当作打底 冲冲冲 | 【统称】别犹豫 还可以当【第二场景】 【行动词】 |

**报价用词约束**：不用「仅售 / 只要 / 到手价 / 券后」，用日常口语（如「一杯奶茶钱」「XX 出头」「XX 多米」——按你目标市场的口语习惯选）。数字必须低于同类心理预期。

## 5. 切点表（位置不许动）

| 切点 | 落在哪个词上 | 画面必须出现什么 |
|---|---|---|
| 0:02.6 | 硬指标 1 的第一个字 | 产品实物特写，直接展示该指标（对比/受力/近景） |
| 0:04.3 | 硬指标 2 的关键词 | 状态演示，占满画面中心 |
| 0:07.0 | 工艺/细节词 | 微距或手部操作，越快越好 |
| 0:09.9 – 0:10.3 | 体感词 | 连切 2–3 次，节奏在此处最密 |
| 0:13.8 | 「性价比拉满」 | 产品 + 价格意象同框 |
| 0:15.1 | 「但……」的反打句 | 换到最好看/最好用的一个状态镜头 |
| 0:17.4 | 第二使用场景 | 场景切换，最后再切回正面收尾 |

**切镜规则**
- 只切在关键词上，**绝不在句子中间切**
- 切点前后各留 1 帧稳定帧，不做转场特效、不加扫光/闪白
- 0:00.0 – 0:02.6 **不做画面变化**（这是原片的风险点，见下）
- 全片总切点 7–9 次，不要更多

**可选优化（推荐，但属于对原片的偏离）**：把 P1 最强的那个 0.5 秒演示镜头**前置到 0:00.2 做预告**，再切回 0:00.7 开始讲钩子。原片前 2.5 秒静止画面在信息流里容易被划走，前置预告能改善前 3 秒留存。

## 6. 视听系统

| 维度 | 规格 |
|---|---|
| 影调 | 自然光 / 室内常亮，不棚拍、不打高光、不做色卡校准感 |
| 机位 | 手持或简易固定，轻微呼吸感；产品实物始终占画面中心 |
| 画质 | 允许轻微噪点与生活化杂乱背景，**刻意不精修**——强化「自用分享」人设 |
| 字幕 | 全片全程硬字幕，思源黑体类，白字 + 细描边，位置固定，**不要逐字花字、不要弹跳动画** |
| 音轨 | 单人干声口播 + 极低音量无版权 BGM（BGM 不得盖过口播换气点） |
| 留白 | 0:20.2 后保留 0.4–0.5 秒黑场或定格，不要突然截断 |

## 7. 交付规范

- 母版：1280×720 横版，30fps，20 ± 1s
- 竖版投放：重新裁切为 9:16 时，**必须保证 0:04.3 与 0:10.0 两个演示点完整落在画面中心**，宁可缩小画面也不裁掉
- 交付三版：横版母版 / 竖版裁切 / 竖版重新构图的保险版
- 音频：-14 LUFS 左右，口播峰值不过载
